# 📚 Matematyka wyższa – Materiały dla Studentów i Pracowników Naukowych

Kompleksowe notatki z matematyki na poziomie pierwszych lat studiów. Przeznaczone dla studentów **matematyki**, **fizyki** oraz kierunków pokrewnych.

---

## 📖 Zawartość

| Rozdział | Tematy |
|----------|--------|
| **Teoria mnogości** | Zbiory, relacje, funkcje, iloczyn kartezjański |
| **Analiza matematyczna** | Ciągi liczbowe, granice, zbieżność, ograniczoność |
